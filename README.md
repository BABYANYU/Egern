# Egern 模块库

为 Egern 提供延迟测试、代理线路查询和 Codex 额度小组件。

| 模块 | 功能 | 订阅地址 |
|---|---|---|
| Latency | 在节点详情测试代理延迟和抖动 | [模块链接](https://raw.githubusercontent.com/BABYANYU/Egern/refs/heads/main/modules/Latency.yaml) |
| Route | 在节点详情查看代理入口与落地 IP 的位置和运营商 | [模块链接](https://raw.githubusercontent.com/BABYANYU/Egern/refs/heads/main/modules/Route.yaml) |
| Codex | 通过桌面小组件查看 5 小时与每周额度 | [模块链接](https://raw.githubusercontent.com/BABYANYU/Egern/refs/heads/main/modules/Codex.yaml) · [参数与使用指南](docs/codex.md) |

在 iPhone 的 Egern 中打开「工具 → 模块」，粘贴所需订阅地址，保存并启用。Latency 和 Route 可在节点详情使用；Codex 需在设备本地填写 access token、account ID 及现有策略组，并添加 Codex 小组件。首次可将模块添加到一个备份的配置中验证。
